fix: keep a hand-written variant on a known package

The previous commit stopped writing variants for the protocols OpenCode
already understands, which is right for the levels it derives itself. But a
standard level that carried its own headers or body is the user's variant,
and OpenCode merges named variants over the derived ones, so dropping it lost
their headers. It is written back now, with the overlay refreshed for the
current protocol. A custom package still gets every selected level, as
before.

Verified against OpenCode 2.1.3: a Chat model with a `high` variant that has
its own headers keeps `low,high`, and a custom package shows `low,high`.
